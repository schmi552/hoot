## Agent skills

### Issue tracker

Issues and specs are local markdown files under `.scratch/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-role vocabulary (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.

## Writing style

Write this in ASD-STE100 (Simplified Technical English), about 80% of
the way: follow its writing rules, but do not force the approved
vocabulary where it makes the text awkward.

## Decisions

Whenever we make an architecture decision, or any other decision that should be recorded, ask the user if they want to create an ADR.
