# Expected time is zero on Saturday and Sunday

The spec has no setting for workdays. Expected time is work hours minus lunch on Monday to Friday and zero on Saturday and Sunday, so a weekend does not show a warning colour. We did not choose "every day is a workday", because every weekend would look like missing time. We did not add a workday setting, because no ticket asks for one. If a user works on other days, a later ticket must add that setting.
